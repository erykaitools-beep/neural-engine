# Scope and provenance

This is a curated research release, not a copy of the entire development machine, the private archive, or the implementation of a production agent. Its parent public Git history contains only the original introduction. Synthetic stimuli were generated for these tasks; there are no patient recordings, personal text corpora or participant records in the selected inputs.

## How the release was made

- Selected by experiment, not by favorable outcome. The original completion records, sealed source-file digests and published-run outputs were examined before export. Only scientific fields from mixed operational records were copied into this tree. The original archive was not edited.
- Spatial panels, raw seed output files, spatial checkpoints, the rhythm input/measurement container, confirmation raw waves, banks and transactions were copied from completed runs. Their scientific scores are recomputed from lower-level evidence.
- Cohort result JSONs are losslessly gzip-compressed; [original uncompressed SHA-256 values](../configs/cohort/uncompressed-sha256.json) are included. Common starting states were taken from the prior B80 checkpoints, not fitted to the results. Prefix NPZs are **projections**, not the original full dump; their companion JSON records identify the original dump hash and checkpoint. Archived reset-control metadata is not a new execution of a reset control.
- The temporal and spatial implementations are extractions from the project's research source. Private module searches, host paths, machine supervision and output directories were replaced by relative imports, a reference solver and a separate launcher. The confirmation port explicitly passes the row class that the historical implementation injected through function globals. None of these packaging edits is an experimental treatment.
- [Source mapping and original digests](source-map.json) identify the sources of the extracted algorithms without publishing private directory structure. [Release checksums](../SHA256SUMS) identify the candidate bytes. Neither is an independent peer review, attestation of ownership or signature.
- Python and NumPy are external dependencies, not vendored libraries. No external simulation engine, pretrained model, copied scientific article or private correspondence is included. The numerical protocols use engineered quantities; biological inspiration does not certify human parameters.

## AI assistance and accountability

Eryk Wyrebek directed the research, set its aims and approved study and publication decisions. OpenAI Codex and ChatGPT assisted with designing controls, implementing and debugging software, interpreting results and editing the research documentation. The public release port and evidence checks were prepared with Codex. AI-generated descriptions were checked against artifacts; code and counts are provided so others can challenge them. Model-assisted checking and separately coded scorers are not external scientific replication. Neither tool nor its provider is listed as an author, endorser or independent validator.

The report has its own registered metadata and license. There is no software DOI in this release, no claim of peer review, and no claim to be the first implementation of calcium-dependent plasticity, inhibitory routing, temporal gates or confirmation filters.
