# Release review and known gaps

**Scope.** This review covers the proposed distribution tree, not all private research material and not an external hosting service. It is a human-reviewable export. A passing check is not a guarantee that no scientific, privacy or security issue remains.

| Check | What was checked | Boundary |
|---|---|---|
| Evidence | Local source-to-release selection; archive closure hashes for the three main studies and the flash pilot, original cohort archive hashes, selected prefix arrays and their original dump hashes. Headline scores recalculated from lower-level records. | A valid hash establishes byte identity with its reference, not scientific truth. |
| Numerical port | Generation of held-out panels; restoration of spatial weights; a frozen spatial panel; one full rhythm batch including spikes, gate and currents; one 48-lane pre-feedback confirmation batch compared across all saved arrays. | No new weight training, external-lab replication or cross-platform numerical certification. |
| Publication | Version DOI, creator, date, version and report license checked against the registered DataCite record. | This repository links to Zenodo. It does not redistribute or certify byte identity of a final PDF; an author-review copy is not used as the version of record. |
| Privacy | Explicitly selected project-owned research files; local text and structured-content inspection including decompressed cohort JSON and numeric-only NPZ members. No mail, machine logs, service configuration, internal agent instructions or private directories exported. | Public author attribution and public repository/publication URLs are intentional. Numeric stimulus “addresses”, masks and checkpoint hashes are not network credentials. |
| Software and data handling | No bundled executables, wheels, object arrays, symlinks, external service calls by the scorer, install-time training, GitHub workflows or credential requirements. Archive inputs use numeric arrays, no pickle. Small binary files encode fixed contact states. | Use a trusted release. SHA256SUMS is unsigned, and the research tools are not sandboxed parsers for hostile archives. Python plus installed NumPy is executable code. |
| Release mechanics | The distribution is separate from the private history. License scopes for the report, software and synthetic data are explicit. | This is a candidate, not a public code release. Rights-holder approval for the proposed software/data terms and the exact payload is outstanding. |

The original operational supervisors, native shared objects, host paths and private research notes are intentionally omitted. The public launcher supervises a new process; it does not reopen a historical run. Fresh training comparisons are provided for future reproducers, not counted as successful runs in this review.

**Offline privacy check coverage:** the ordered payload inspection decoded the compressed per-seed JSON results and numeric NPZ members before reaching a text-pattern alert in the source tree. Manual inspection identified that alert as a NumPy matrix multiplication expression, not an email address. A redundant second full scan was stopped by the hardware safety monitor and was not retried. The remaining plain-text source and release documents received separate static checks; no matching credentials or private endpoints were found. This review does not claim two completed scans, a cloud security certification, or an absolute absence of secrets.

**Release checklist:** verify the manifest and tests on an independent checkout; inspect the scope and terms in `LICENSE`; obtain the maintainer's explicit license and publication decision; publish only that reviewed tree; if anything changes, regenerate checksums and repeat the release checks. Do not distribute a private lab archive as a substitute.
